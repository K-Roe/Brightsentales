## Artwork and scene

- Unity's `Assets/BrightTalesBridgeV1/MaxApprovedIdle.png` is a byte-identical copy of BrightTales `public/art/max-0.png` (434 × 724 RGBA; SHA-256 `7D1C4A26BEBDABD85B2114B8CA61DF4E5F83302AB21AA8C895F5438D75A98D24`). The approved source was not edited.
- BrightTales' approved Brightling Life V2 blink is generated by `makeEyeLayer(sprite, 'male', 'idle')` in `src/eyeLayers.ts`. `MaxBlinkOverlay.png` was rendered from that function against the approved PNG into a transparent canvas of the same 434 × 724 size. The unchanged full-body image stays visible below it. Unity uses the same registration, pivot and 100 pixels per unit for both sprites; only the eye overlay is enabled for the approved 0.15-second closed interval.
- Open `C:\Users\karlr\repos\BrightTalesUnityTest\Assets\Scenes\MaxBridgeDemo.unity`. It has the approved Max, an orthographic 2D camera, a neutral background and the existing bridge receiver. Maxine, the Studio renderer, approved actions and their timing are untouched.

## Bridge and controls

The V0 loopback receiver remains at `127.0.0.1:17843`. `GET /health` and `GET /ping` retain their V0 responses. `POST /command` with JSON `{"command":"max.blink"}` queues work to Unity's main thread. It returns HTTP 202 with `status: accepted` only after Unity starts the blink; invalid bodies return 400, unknown commands 404, a second blink during the closed interval 409, and unavailable Max or main-thread timeout 503. The receiver checks local browser origins and keeps the same loopback-only transport.

The experimental Studio **Unity Connection** panel has **Blink Max** beside Connect, Disconnect and Ping. It is available only while connected and reports that Unity *accepted* the command, without claiming visual completion. No Scene Maker or project-file setting was added.

## Run the demo

1. Open the Unity project in Unity 6.6, open `Assets/Scenes/MaxBridgeDemo.unity`, wait for compilation, and press **Play**. Max should remain centered in Game view.
2. From the BrightTales repository run `npm run dev` and open the printed local address. Choose **Unity Connection**, then **Connect**, optionally **Ping**, and **Blink Max**.
3. Watch Unity Game view for one blink and a return to open eyes. Repeated clicks after the blink finishes trigger another blink; a command while it is in progress is reported as busy.
